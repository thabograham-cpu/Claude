# DoF Guide

Code: `camera.dof(rig, fstop, focus=obj, bone="head")`, `camera.rack_focus(rig, f0, f1, a, b)`. Rack focus moves a focus empty between subjects, so the pull is smooth.


- Focus object = subject empty
- Shallow for hero; deeper for environments
- Preview Eevee; confirm Cycles if final
- Avoid focus hunting mid-shot unless motivated
